# agent-task-runner

Orchestrateur externe léger qui exécute une file de tâches de développement de manière autonome, séquentielle et reproductible via des CLI d'agents IA (`claude -p`, `agy`, etc.).

Les spécifications techniques sont dans [`docs/specification.md`](docs/specification.md).

> Statut : en cours de conception, l'implémentation n'a pas encore commencé.
